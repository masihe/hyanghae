취향으로 밝아지는 향 지도

개인 취향을 원으로 감싸는 대신, 향수마다 “당신 취향과 얼마나 맞는가”를 계산해 빛으로 표현합니다. 취향이 지도 여러 곳에 흩어져 있어도 그대로 보여집니다. 아래는 실제 향 지도 데이터 200개로 그린 것입니다.

밝고 큰 점일수록 취향에 맞습니다. 어두운 점은 같은 지도 위의 나머지 향수입니다 — 사라지지 않습니다. 취향 밖도 계속 보이니 탐험할 여지가 남습니다.

원인은 UMAP이 아닙니다

향수 하나가 향조를 8개 동시에 가집니다. Byredo Bal d'Afrique는 우디이면서 얼시이면서 시트러스이면서 머스키입니다. 2차원 지도에서 향수는 점 하나라서 소속 8개를 표현할 방법이 없습니다.

게다가 woody는 200개 중 122개(61%)가 가지고 있습니다. 배경이지 특징이 아닙니다. 61%를 감싸는 원은 결국 지도 전체입니다. 투영 방법을 t-SNE나 다른 것으로 바꿔도 같은 문제가 남습니다.

빛은 이 문제를 피해 갑니다

경계를 그리지 않으니 취향이 몇 군데로 나뉘어 있어도 괜찮습니다. “코코넛 + 솔티”를 골라보면 지도의 양 끝 두 곳이 밝아집니다 — 그게 왜곡이 아니라 사실이고, 사용자에게도 정직한 그림입니다.

계산

적합도는 이렇게 구합니다

새 데이터가 필요 없습니다. 지금 korea_scent_map_v2.json에 들어 있는 향수별 top_accords(향조 8개와 강도 0~100)만 씁니다.

적합도 = (취향 향조들의 강도 합) ÷ (최대 가능 합)

취향 = {coconut, salty} 이고
어떤 향수의 강도가 coconut 82, salty 0 이면
적합도 = (1×82 + 1×0) ÷ (2×100) = 0.41 → 전체 최댓값으로 정규화

나눗셈 하나라서 브라우저에서 즉시 계산됩니다. 서버 호출도, 사전 계산도, 지도 재생성도 필요 없습니다. 사용자가 취향을 바꾸면 그 자리에서 다시 밝아집니다.

취향 향조에 가중치를 다르게 주고 싶다면(예: 코코넛 2배) 분자·분모의 계수만 바꾸면 됩니다. 이 시안은 전부 1배로 두었습니다.
