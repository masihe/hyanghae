# 47. Domain Lexicon v1.7 → v1.8 변경 기록

근거: `42_lexicon_expansion_priority.md` — `woody` 가 v1.7 기준으로도 실패 46회 · 영향권 245로 1위
재현: `./venv/Scripts/python.exe 41_lexicon_ndcg.py <v1_7> <v1_8>`
작성: 2026-09-14 · API 호출 0회

## 결론

- **행을 더하지 않았다.** `kr.source.wood` 의 별칭에 `숲`·`산림`·`편백` 만 더했다. 53행 유지
- 전체 NDCG@5 0.4654 → **0.4688 (+0.0035)**. 영향권 39건에서 **+0.0536**
- **`woody` 별칭 확장은 팀 문서 기준으로 거의 소진됐다.** 이게 이 문서의 핵심이다
- **예상이 틀렸다.** 이득이 없거나 음수일 것으로 봤으나 소폭 양수였다

## 팀 문서에 남은 것이 거의 없다

Woods 장에서 아직 안 쓴 후보 28개를 전부 검토했다. **대부분이 다른 accord 를 가리킨다.**

| 뺀 것 | 왜 |
|---|---|
| `오우드` · `오우디한` | `oud` accord 가 따로 있다 (8,298개) |
| `패출리` · `패출리한` | `patchouli` accord 가 따로 있다 (14,822개) |
| `흙기` · `흙내` | `earthy` accord 가 따로 있다 (19,049개) |
| `담백한` · `담담한` · `차분한` · `편안한` · `그윽한` | 향이 아니라 **인상**을 가리킨다 |
| `마른` · `오래된` · `단단한` · `잘 다듬어진` · `날렵한` | 질감 형용사. 나무 전용이 아니다 |
| `자연스러운` | 이미 사전 항목이다 (`NO_MAPPING`) |
| **`뿌리`** | **`향수를 뿌리다` 에 걸린다.** 문자열 포함 매칭이라 위험하다 |

남은 것을 평가셋에서 세어보니 **거의 안 나온다.**

```
샌달우드  0건        절간  0건        백단  1건 (이미 `백단향` 별칭이 있다)
```

**유일하게 남은 지렛대가 `숲` 이었다.**

## `숲` 을 넣을지가 유일한 판단이었다

`kr.scene.rainy_forest`(비 오는 숲)가 이미 `숲 냄새`·`숲 속` 을 별칭으로 갖고
`mossy`+`earthy`+`green` 으로 보낸다. `숲` 을 `woody` 에도 넣으면 **같은 말이 두 항목에
걸려 조건이 늘어난다.**

> **사전 등록** — 예상: 이득이 거의 없거나 음수. 숲 문장 39건 중 표본 4건이 전부
> 이미 `나무` 로 `woody` 를 받고 있었고, 비 오는 숲과 겹치면 조건이 늘어 검색이 좁아진다.
> 판정: v1.7 보다 나으면 채택. 아니면 `woody` 별칭 확장은 소진된 것으로 결론낸다.

## 예상이 틀린 부분

이득이 없거나 음수일 것으로 봤다. 근거는 *"표본 4건이 전부 이미 `나무` 로 조건을 받고 있다"* 였다.
그런데 **표본 4건이 전체 39건을 대표하지 않았다.** 실제로는 4건이 `NO_CONDITION` 에서
벗어났고 2건이 완화에서 정밀 검색으로 올라섰다.

**표본 4건으로 39건을 판단한 것이 잘못이었다.** 다만 사전 등록한 판정 기준(v1.7 보다 나으면 채택)은
그대로 적용했으므로 결과를 보고 기준을 바꾼 것은 아니다.

## 이제 무엇이 남았나

`woody` 는 팀 문서를 다 썼다. 더 넓히려면 **다른 출처가 필요하다.**

| 남은 길 | 상태 |
|---|---|
| 미매칭 로그 | 아직 구현 전. 실사용 표현이 여기서 나온다 |
| `ai_summary` | 영어 코퍼스라 한국어 표현을 못 준다 |
| 팀 문서 확장 | Woods 장에 표현을 더 쓰는 것. 사람 작업 |

`spec.md` §7.2 가 사전 확장의 출처를 **팀 문서 · 미매칭 로그 · `ai_summary`** 로 제한한다.
평가셋 문장을 보고 표현을 고르면 leakage 가 되므로 하지 않았다.

## 주의할 것

**① `숲` 이 `woody` 와 `mossy`+`earthy`+`green` 둘 다로 갈 수 있다.** 지금은 겹치는 질의가
드물어 문제가 안 되지만, **같은 말이 문맥에 따라 다른 곳으로 가는 상태**다. 정리 대상이다.

**② 코퍼스 검증을 안 했다.** `verification_status` 는 `UNMEASURED` 그대로다.

**③ `뿌리` 를 뺀 이유를 기억해야 한다.** 문자열 포함 매칭이라 `향수를 뿌리다` 에 걸린다.
형태소 분석이 들어오면 다시 검토할 수 있다.
