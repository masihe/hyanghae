## 안건 1 — 향수 13만 개를 DB 에 넣을 것인가

**담당** 권영민 · 김경린 **우선** 이 안건이 나머지 셋을 결정한다. 먼저 한다

### 문제

자연어 추천은 향수 **13만 개 전체**를 뒤진다. 지금 DB 에 있는 것은 향 지도용 200개다.

| | DB 현재 | 자연어 추천에 필요 |
|---|---:|---:|
| 향수 | **200** | 131,930 |
| accord 종류 | **60** | 92 |
| `perfume_accords` | **1,598행** | 약 80만 행 |
| `people`(평가자 수) | **컬럼 없음** | 정렬에 필수 |

> 출처 — `backend/db/seed/README.md` 가 적재 후 기대값을 명시한다.
> `perfumes 200 | perfume_accords 1598 | accords 60`
> 실제 DB 를 조회해 확인한 것은 아니다. 회의에서 한 번 세어보면 확실하다.

### 선택지

| | 내용 | 대가 |
|---|---|---|
| **A. 넣는다** | Spring 이 SQL 로 검색. AI 서비스는 조건 추출만 | 마이그레이션(`people` 컬럼 추가), accord 60→92 확장, 약 80만 행 적재, **기존 향수 상세·검색 기능에 영향** |
| **B. 안 넣는다** | AI 서비스가 CSV 5MB 를 들고 검색까지 | 향수 정보가 **두 곳에** 존재. 나중에 어긋날 수 있음 |
| **C. 나중에** | 지금은 B, 일정을 잡아 A 로 | 이행 비용을 뒤로 미룸 |

**참고** — `spec.md` 의 원래 설계는 A 다. *"Python 서버는 데이터베이스에 접근하지 않는다.
검색은 Spring + PostgreSQL 이 한다."* A 로 가면 AI 서비스가 갖는 데이터가 **19KB(사전)로 줄어든다.**

## 안건 2 — AI 서비스를 배포에 어떻게 태울 것인가

**담당** 김경린

### 문제

```
Jenkinsfile            backend(Gradle) · frontend(npm) 만.  AI 언급 0건
compose.manual-test    postgres · redis 만
배포 트리거            master 브랜치에서만
```

필요한 것은 빌드 단계(Python 의존성), 컨테이너 또는 프로세스 정의, 헬스체크다.
**데이터 파일은 저장소에 5MB 로 들어 있어 별도 다운로드가 필요 없다.**

### 선택지

| | 내용 |
|---|---|
| **A. 파이프라인에 추가** | `Jenkinsfile` 에 AI 단계, `compose` 에 서비스 추가 |
| **B. 수동 배포** | 서버에서 직접 띄우고 관리 |
| **C. 1차 릴리즈에서 제외** | 로컬 시연만. 다음 릴리즈에 |

**확인이 필요한 것** — 서버에 Python 런타임이 있는가. 리소스는 되는가
(적재 시 메모리 약 100MB, 이후 상주).

## 안건 4 — 향 조건을 못 뽑는 경우의 화면

**담당** 송가연 · 차서영

### 문제

```
합성 평가셋 600건 중   134건 (22.3%) 이 향 조건을 하나도 못 뽑음
실사용자 설문 155건 중  75건 (48.4%) — 실사용은 더 어렵다
```

응답이 이렇게 온다.

```json
{ "status": "NO_CONDITION",
  "diagnostics": { "unmatched_hint": "문장에서 향 조건을 하나도 찾지 못했다..." } }
```

> **인기 향수를 대신 보여주면 안 된다.** 추천처럼 보이지만 근거가 없다. 나중에
> "왜 이게 나왔냐" 는 질문에 답할 수 없고, 요구사항 NLR-07(추천 이유 제공)을 어긴다.

### 선택지

| | 내용 |
|---|---|
| **A. 재입력 유도** | *"어떤 향을 원하시는지 좀 더 알려주세요"* |
| **B. 예시 문장 제시** | 되는 표현으로 만든 예시 3~4개를 버튼으로 |
| **C. 향 지도로 유도** | 말로 표현하기 어려우면 지도에서 고르게 |

B·C 는 **막힌 사용자를 다른 기능으로 보내는 효과**가 있다.
