```

검증            프로세스 안에서는 캐시가 듣고, 재시작하면 옛 추정을 물려받지 않는 것을 확인
```

**⚠ `DECISIONS.md` N15 를 일부 뒤집는 변경이다.** N15 가 "⑤단계 추정 + 파일 캐시" 로

## 8. 왜 실사용 데이터가 필요한가

**개선을 판정할 수 없는 단계에 이미 왔다.** 측정 기록 17번이 근거다.

```
같은 프롬프트로 다시 부른 것만으로 NDCG 가 +0.0608 움직였다

이 프로젝트에서 잰 개선
  분석기 +0.0025 · 노트 브리지 +0.0254 · 임베딩 +0.0347 · 사전 v1.15 +0.0000
```

**개선이 전부 잡음보다 작다.** 그리고 설문 143건에 정답 라벨이 없다(`spec.md` §8 3번).

**320 이 병합되면 이 상황이 바뀐다.** 사용자가 무엇을 클릭하고 얼마나 만족했는지가
쌓이기 시작한다. 그때까지는 `lexiconVersion`(3장)을 넣어 두는 것이 중요하다.
