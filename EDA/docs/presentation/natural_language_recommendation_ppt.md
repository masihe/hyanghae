# 자연어 기반 향수 추천 — PPT 전달 자료

> 향수를 잘 몰라도 원하는 느낌과 상황만 말하면, 그 표현을 분석해 실제 향수 데이터까지 연결하는 추천 경험을 만든다.

## 전체 스토리

**향수 데이터 분석**  
→ **사용자 표현과 데이터 용어 사이의 간극 발견**  
→ **자연어를 추천 조건으로 구조화**  
→ **실제 향수 데이터와 비교해 Ranking**  
→ **추천 향수와 추천 이유 제공**

---

# 1. 약 13만 개 향수 데이터 분석

## 핵심 메시지

> 단순 제품 목록이 아니라 향의 구성과 사용자 인식 데이터를 함께 활용해 추천 구조를 설계한다.

Fragrantica 기반 **131,930개 향수 데이터**를 분석했다. 향의 구성뿐 아니라 계절, 시간대, 강도, 지속력, 사용자 인식, 유사 향수 관계까지 추천에 활용할 수 있다.

## PPT에서 강조할 숫자

| 강조 숫자 | 의미 |
|---:|---|
| **131,930개** | 분석한 전체 향수 |
| **약 97.9%** | Accord 데이터 보유율 |
| **약 98.1%** | Note 데이터 보유율 |

## 참고 숫자

| 참고 숫자 | 의미 |
|---:|---|
| **92종** | 데이터에서 확인한 Accord 종류 |
| **2,523종** | 데이터에서 확인한 Note 종류 |

## 추천에 활용할 수 있는 데이터

| 데이터 | 활용 방향 |
|---|---|
| Accord | 향수의 전반적인 향 계열 파악 |
| Note | 향수를 구성하는 구체적인 향 요소 파악 |
| Season | 계절별 적합도 비교 |
| Day / Night | 사용 시간대 적합도 비교 |
| Sillage | 향이 주변으로 퍼지는 정도 비교 |
| Longevity | 향이 유지되는 정도 비교 |
| Community | 사용자들이 실제로 느낀 특성 반영 |
| Similar Perfume | 비슷하다고 평가된 향수 관계 활용 |

## 데이터 관계 분석에서 확인한 내용

- **Bergamot**는 **Citrus** 계열과 강하게 연결됐다.
- **Vanilla Note**는 **Vanilla Accord**와 강하게 연결됐다.
- **Fresh·Citrus·Green** 계열은 **Spring·Summer·Day** 쪽 사용자 인식과 연결됐다.
- **Warm Spicy·Amber·Woody** 계열은 **Autumn·Winter** 쪽 연결이 관찰됐다. 시간대에서는 특히 **Warm Spicy**가 **Night** 성향을 보였다.

향 구성 정보와 계절·시간대에 대한 사용자 인식 사이에 추천에 활용할 수 있는 관계가 존재함을 확인했다.

### 화면 구성 아이디어

중앙의 향수 데이터에서 `Accord`, `Note`, `Season`, `Day/Night`, `Sillage`, `Longevity`, `Community`, `Similarity`가 여러 갈래로 펼쳐지는 형태가 적합하다.

# 2. 사용자는 데이터의 언어로 향수를 찾지 않는다

## 핵심 메시지

> 향수를 잘 모르는 사용자는 전문 용어보다 느낌, 상황, 분위기, 선호와 비선호를 자연어로 표현한다.

| 향수 데이터의 표현 | 실제 사용자의 표현 |
|---|---|
| Vanilla | “여름에 쓰기 좋은 은은한 바닐라 향” |
| Woody | “비가 온 뒤의 숲 같은 향” |
| Summer | “더운 날에도 답답하지 않은 향” |
| Low Sillage | “소개팅할 때 부담스럽지 않은 향” |
| Sweet | “바닐라 향은 좋은데 너무 단 건 싫어” |

데이터에는 `Note`, `Accord`, `Season`, `Sillage`처럼 정리된 값이 있다. 그러나 사용자는 같은 요구를 느낌과 장면이 담긴 문장으로 말한다.

## 해결해야 할 간극

**향수 데이터의 언어**  
Vanilla / Woody / Summer / Low Sillage

↓ **자연어 해석**

**사용자의 언어**  
“비 오는 숲 같은 향” / “은은하고 오래가는 향”

> 향수 데이터와 사용자 표현 사이의 간극을 자연어 해석으로 연결한다.

---

# 3. 자연어를 데이터로 변환해 향수를 추천

## 최종 추천 구조

**사용자 자연어**  
↓  
**AI / Parser가 사용자 요구 해석**  
↓  
**추천 조건으로 구조화**  
↓  
**향수 데이터와 비교**  
↓  
**조건에 맞는 향수 Ranking**  
↓  
**추천 향수 TOP N + 추천 이유**

## Query가 추천 조건으로 바뀌는 예시

### 사용자 표현

> “여름에 쓰기 좋은 은은한 바닐라 향인데 너무 단 건 싫어”

### 해석된 추천 조건

| 조건 | 해석 결과 |
|---|---|
| 향 | Vanilla |
| 상황 | Summer |
| 강도 | 은은한 향 |
| 회피 조건 | 너무 단 향 |

이렇게 정리된 조건을 실제 향수의 Accord, Note, Season, Sillage 등과 비교해 적합한 후보의 순위를 정한다.

## AI와 추천 알고리즘의 역할 분리

| 역할 | 담당하는 일 |
|---|---|
| AI / Parser | 사용자의 모호한 자연어를 이해하고 추천 조건으로 정리 |
| 향수 데이터 + 추천 알고리즘 | 구조화된 조건을 근거로 실제 추천 향수를 결정 |

> **AI는 사용자의 말을 이해하고, 실제 추천은 향수 데이터에 근거해 결정한다.**

목표는 LLM이 알고 있는 향수를 임의로 제안하는 구조가 아니다. 자연어 해석과 실제 향수 Ranking을 분리해 추천 결과가 보유 데이터에 기반하도록 설계한다.

# 4. 최종 목표

## 제공하려는 사용자 경험

> 향수를 잘 몰라도 원하는 느낌만 말하면, 그 표현을 분석해 실제 향수까지 연결해주는 추천 경험

### 사용 예시

**사용자**

> “비 오는 여름밤에 산책할 때 어울릴 만한 시원한 향”

**서비스**

1. 사용자의 표현을 해석한다.
2. 향과 상황 조건을 정리한다.
3. 관련 향수 데이터를 탐색한다.
4. 조건에 적합한 향수를 추천한다.
5. 왜 추천했는지 데이터에 근거해 설명한다.

## 최종 목표 한 문장

> **원하는 향을 설명하는 것만으로 실제 향수를 발견할 수 있는 탐색 경험을 제공한다.**

# 5. 현재 진행 상황과 앞으로의 계획

## 현재

- Fragrantica 데이터 구조 및 품질 분석 완료
- 향·계절·시간대 등 Feature 관계 분석 완료
- 실제 사용자 자연어 **200개 Golden Set** 구축
- 자연어 해석 방식 검증 진행 중

**Golden Set**은 시스템이 자연어를 제대로 이해했는지 비교하기 위해 사람이 정답을 작성한 평가 데이터다.

현재 검증에서는 기존의 단순 Rule 방식만으로 실제 사용자의 다양한 표현을 충분히 처리하기 어렵다는 점을 확인했다.

## 앞으로의 계획

**Rule 기반 해석**  
→ **Rule 확장**  
→ **LLM 기반 자연어 해석**  
→ **동일한 사용자 Query로 비교 검증**  
→ **최종 자연어 해석 방식 결정**  
→ **향수 추천 Ranking과 연결**

> Rule과 LLM 기반 방식을 같은 평가 데이터로 비교한 뒤 최종 방식을 결정할 예정이다.
